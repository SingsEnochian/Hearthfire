# Hearthfire · Braid Packet Runtime Inheritance

Hearthfire-hosted modules inherit the canonical Hearthgate Braid Packet rather than inventing parallel active state.

Canonical schema:

```text
SingsEnochian/Flameclyffe/starwell/deep-observer/schemas/braid-packet-v1.schema.json
```

Canonical runtime semantics:

```text
SingsEnochian/Flameclyffe/apps/starwell/src/hearthweave-kernel/braided-spine.js
```

Every hosted adapter preserves:

```text
packet_id
state_fingerprint
PREMAQ registry
Asking
world relation
Magic Spine state
Science/Mathematics Spine state
Physical Spine state
Sevenfold Chorus
Thirteenfold Council
Receiving Spring
answer
return
lineage
```

Hearthfire routes and hosts this state. It does not create a rival semantic registry.
